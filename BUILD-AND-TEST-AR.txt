بناء ios app وتجربته

الحزمة مصدر معدّل، وليست IPA جاهزة للتثبيت. تضم الأيقونات وSVG والاختبارات والتقرير وworkflow. لم يتوفر Xcode أو iOS SDK للبناء هنا.

GitHub Actions
1. ارفع محتويات المشروع إلى مستودع GitHub مع مجلد .github.
2. افتح Actions ثم build-ipa ثم Run workflow.
3. عند نجاح البناء نزّل artifact باسم ios-app-ipa.
4. فك artifact لتحصل على ios-app-unsigned.ipa.
5. وقّع وثبّت بأداة مناسبة مثل AltStore أو SideStore، ثم فعّل JIT المناسب لجهازك.

الـ workflow يحمل مكتبات QEMU/ANGLE وfirmware من إصدار Husk upstream. الوصول إلى الإصدار والتوافق والتوقيع لم تُختبر هنا. قد تحتاج تحديث الاعتماد أو بناء المكتبات من المصدر إذا فشل تحميله أو تغيّرت واجهاته. لا تعطل الاختبارات لتجاوز فشلها.
اسم target وscheme الداخلي Husk متعمد؛ الاسم الظاهر ios app.

macOS محليًا
بعد تجهيز المكتبات وguest المطلوبة:
chmod +x scripts/*.sh
python3 tests/security_regression.py
cd src/app && xcodegen generate && cd ../..
bash scripts/package_ipa.sh "$HOME/Desktop/ios-app-unsigned.ipa"

يلزم Xcode وXcodeGen وqemu-img والاعتمادات الأصلية. راجع scripts/build_ios.sh وdocs/03-phase0-runbook.md. التغليف يمنع استخدام نسخة قديمة عند فشل البناء.

تجربة الجهاز
1. الاسم والأيقونة والتبويبات والبحث والإعدادات والملفات.
2. التثبيت الأول وJIT والعودة من الخلفية، مع تدوين نوع الجهاز وإصدار iOS.
3. الاستعادة ثم الإقلاع البارد، والصوت والتدوير والعودة من الضيف.
4. APK موثوقة والتنزيل وإلغاؤه وانقطاع الشبكة وملف تالف.
5. ملف باسمه مسافة واقتباس مفرد، ثم مشاركة السجل من الإعدادات.
6. اترك التشغيل الأصلي التجريبي مغلقًا أولًا؛ استخدم APK موثوقة فقط إذا اختبرته.

احتفظ بأول خطأ Xcode عند فشل البناء. عند فشل التشغيل احتفظ بالسجل والخطوات ونوع الجهاز وإصدار iOS. احذف الأسرار قبل مشاركة السجل.

التوافق
HTTP غير المشفر على المضيف محظور. JSON بسيط يحتاج sha256 لكل APK. بنية DEX غير صالحة أو رأس غير مدعوم يُرفض. التشغيل الأصلي يحتاج إقرار المخاطر الجديد.
